# Kbd

One key of the keyboard. `Kbd` in `src/components/Kbd.tsx`.

- 20px high, 6px radius, the `surface` ground with the control outline, 11px mono text in `muted`.
- It sits in running text, a hint or a tooltip: "Press Enter to send, Shift+Enter for a new line".
- One `Kbd` for each key. Write a key the way it is printed: "Enter", "Shift", "Esc", "⌘".
- It is a `<kbd>` element, so a screen reader reads its text.
