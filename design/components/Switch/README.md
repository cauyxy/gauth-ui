# Switch

An on/off setting. `Switch` in `src/components/Switch.tsx`.

- 34 × 20px, ink when on, `rule` when off, a 16px white knob. It needs a `label` for screen readers.
- It sits at the right end of a settings row: label on the left, the switch on the right.
- Only for settings that really change something. A switch with nothing behind it is removed, not shown.
