# FollowUps

Questions to tap under the last reply from Gauth AI. `FollowUps` in `src/learning/FollowUps.tsx`.

- One question per row, each as wide as its text. A long one wraps; it is not cut.
- White with a control hairline, 12px radius, 14px text in `ink-soft`. No fill, no icon, no sparkle: the outline is its one weight.
- They go under the last reply only.
- A tap gives the text to `onPick`. The page sends it as the person's next message.
- With no items it shows nothing.
