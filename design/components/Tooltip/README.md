# Tooltip

A short explanation on hover or focus. `Tooltip`, `TooltipTrigger`, `TooltipContent` in `src/components/Tooltip.tsx` (Radix, 150 ms delay).

- Ink ground, white 12px text, 6px from what it explains.
- Use it to say what a figure means and what it rests on. Never hide an action or the only copy of a fact in one.
